## 🔧 Technical Details

### Offline-First Pattern:
```dart
// OLD (Slow - waits for Firebase)
Future<List<AttendeeModel>> getAttendees() async {
  if (await isOnline()) {
    return await firebaseRepo.getAll(); // 3-5 seconds
  }
  return await localRepo.getAll();
}

// NEW (Fast - loads locally, syncs in background)
Future<List<AttendeeModel>> getAttendees() async {
  final data = await localRepo.getAll(); // <0.5 seconds
  _backgroundSync(); // Don't wait
  return data;
}
```

### Enhanced OCR:
- Processes all text blocks in image
- Extracts names, phones, and locations
- Handles multiple formats (table, list, etc.)
- Returns confidence scores
- Finds ALL attendees, not just first one

### Background Sync:
- Runs every 30 seconds when online
- Triggers on connectivity change
- Queues changes when offline
- Retries failed syncs
- Shows sync status
