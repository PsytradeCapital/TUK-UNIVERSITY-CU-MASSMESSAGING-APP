## INSTALLATION STEPS

### Step 1: Authorize Device
Your device needs USB debugging authorization:

```bash
# Check device authorization dialog on your phone
# Tap "Allow" when prompted

# Then install:
adb install -r build\app\outputs\flutter-apk\app-release.apk
```

If you see "device unauthorized":
1. Check your phone screen for USB debugging authorization dialog
2. Tap "Always allow from this computer"
3. Tap "Allow"
4. Run the install command again

## WHAT'S FIXED IN v1.8.0

### 🔧 Critical Fixes:

1. **SMS Validation** - Messages now go to correct numbers only
   - Validates phone numbers before sending
   - Filters out invalid numbers
   - Shows validation summary in logs

2. **Instant Loading** - Members tab loads immediately
   - No more "Syncing..." delays
   - Loads from local database first
   - No Firestore permission errors

3. **Smart Duplicate Detection** - Bulk import is smarter
   - Only asks for update if data differs
   - Silently increments count if data is same
   - Much faster import process

4. **Resend Message Button** - Added to Reports
   - Click service → "Resend Message"
   - Opens messaging with attendees pre-loaded
   - Easy to send follow-up messages
