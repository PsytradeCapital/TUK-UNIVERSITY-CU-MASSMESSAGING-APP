## 📱 How to Use

### Access Your 128 Contacts:
1. Open the app
2. Tap **"Members"** tab (second icon from left - people icon)
3. See all your contacts instantly!

### Use Autocomplete Search:
1. Start typing a name in search box
2. See dropdown with matching suggestions
3. Tap a suggestion to select it
4. Or keep typing to filter results

### Send Message to All:
1. Go to Members tab
2. (Optional) Apply filters
3. Tap **"Message All"** button
4. Type your message
5. Tap **"Send"**
6. Done! ✅

### Filter Members:
1. Tap **"Location"** chip → Select location
2. Tap **"Year"** chip → Select year
3. Tap **"Category"** chip → Select category
4. See filtered results instantly
5. Tap **"Clear"** to remove filters

### Search for Someone:
1. Type name or phone in search bar
2. See autocomplete suggestions dropdown
3. Tap suggestion or continue typing
4. Tap message icon to send SMS

### Register Attendees:
1. Search for returning attendee (optional)
2. Fill in details
3. If phone already registered in session, you'll see a warning
4. Choose to continue or cancel
5. Registration complete!

## 🔒 Data Safety
